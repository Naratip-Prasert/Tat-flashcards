เว็บแอปแฟลชการ์ดสำหรับท่องคำศัพท์ญี่ปุ่น → ไทย ติดตั้งลงหน้าจอโฮมได้ (PWA) และใช้ออฟไลน์ได้

**เปิดใช้:** https://naratip-prasert.github.io/Tat-flashcards/

## ฟีเจอร์
- **หน้าแรก** เลือกโหมด: คำศัพท์อิอิ / เขียนประโยคอิอิ
- **เขียนประโยคอิอิ**:
  - 🎲 สุ่มแต่งประโยค ระดับ N5–N1 (แต่งใหม่ทุกข้อจากรูปไวยากรณ์ + คลังคำใน `js/sentence-gen.js`)
  - 🎯 เลือกหมวด: ชุดประโยคใน `data/sentences.js` ตามหมวดคำศัพท์
  - 📝 ทำแบบฝึก: เลือกเลเวล → สุ่มหมวด + คำศัพท์ 10 คำ (`js/exercise-bank.js`) → แต่งประโยคจากคำเหล่านั้น 10 ข้อ → สรุปคะแนน
  - ทุกแบบ: สุ่มประโยคไทย → พิมพ์เป็นภาษาญี่ปุ่น (คันจิ/ฮิรางานะ/ผสม) → ตรวจอัตโนมัติ → กดไมค์พูดตาม (ใช้ระบบรู้จำเสียงของเบราว์เซอร์ ต้องต่อเน็ต)
- หน้ารวมคำศัพท์ของแต่ละบท: สถานะ ยังไม่เริ่ม / กำลังเรียน / จำได้แล้ว, ติดดาว, ฟังเสียง, ค้นหา, เรียงลำดับ
- "ทบทวนชุดนี้" เปิดแฟลชการ์ดตามตัวกรองที่เลือกอยู่
- แฟลชการ์ด: แตะเพื่อพลิก, ปัดซ้าย/ขวาเพื่อเปลี่ยนใบ, สลับด้านหน้า ญี่ปุ่น/ไทย, สุ่ม, ซ่อนคำที่จำได้
- ความคืบหน้าเก็บในเบราว์เซอร์ของเครื่องนั้น (localStorage)

## ติดตั้งบน iPhone / iPad
เปิดลิงก์ด้านบนใน **Safari** → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

## โครงสร้างไฟล์
```
index.html            หน้าแอป (HTML + CSS + JS)
data/vocab.js         คำศัพท์ทั้งหมด ← แก้/เพิ่มคำที่ไฟล์นี้
data/sentences.js     ประโยคสำหรับโหมดเขียนประโยค (🎯 เลือกหมวด)
js/sentence-gen.js    ตัวแต่งประโยคอัตโนมัติ N5–N1 (🎲) และรูปประโยคของโหมดทำแบบฝึก
js/exercise-bank.js   คลังคำศัพท์ N5–N1 แยกหมวด สำหรับ 📝 ทำแบบฝึก
js/sync.js            ☁️ ล็อกอิน + ซิงก์ข้ามเครื่อง (Firebase)
js/firebase-config.js ค่าเชื่อม Firebase (ใส่ตามหัวข้อด้านล่าง)
sw.js                 service worker (ออฟไลน์ + อัปเดตอัตโนมัติ)
manifest.webmanifest  ข้อมูลแอปสำหรับติดตั้ง
icon-*.png            ไอคอน
```

## เพิ่ม/แก้คำศัพท์
แก้ `data/vocab.js` แล้ว commit + push — GitHub Pages จะ deploy ให้เองภายใน ~1 นาที
และแอปบนมือถือจะได้เวอร์ชันใหม่ตอนเปิดครั้งถัดไปที่มีเน็ต

```js
{"w": "融点", "r": "ゆうてん", "th": "จุดหลอมเหลว", "note": "หมายเหตุ (ไม่บังคับ)", "ex": "ตัวอย่างประโยค (ไม่บังคับ)"}
```

> ⚠️ สถานะ จำได้/ติดดาว ผูกกับ `id บท-id หมวด-ลำดับคำ` — ห้ามเปลี่ยน id และให้เพิ่มคำใหม่ **ต่อท้าย** หมวด
> (แทรกกลางหมวดจะทำให้สถานะที่เซฟไว้เลื่อนไปผิดคำ) ส่วนบทใหม่ให้ใช้ id ใหม่ เช่น `ch4`

## ☁️ ตั้งค่าล็อกอิน / ซิงก์ข้ามเครื่อง (Firebase ฟรี)
แอปมีระบบล็อกอินแบบชื่อผู้ใช้ + รหัสผ่าน (ไม่ต้องใช้อีเมล) แล้วซิงก์ จำได้/ติดดาว/สถิติเขียนประโยค ทุกเครื่องแบบเรียลไทม์
ถ้ายังไม่ตั้งค่า แอปจะเซฟในเครื่องเหมือนเดิม

1. เข้า https://console.firebase.google.com → **Add project** (ชื่ออะไรก็ได้ เช่น `tat-card`, ปิด Google Analytics ได้)
2. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable → Save**
3. **Build → Firestore Database → Create database** → เลือก location `asia-southeast3 (Bangkok)` (หรือ Singapore ก็ได้), edition **Standard** → Production mode
4. Firestore → แท็บ **Rules** → วางกฎนี้แล้วกด **Publish** (แต่ละคนอ่าน/เขียนได้เฉพาะข้อมูลตัวเอง)
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{db}/documents {
       match /users/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```
5. **Authentication → Settings → Authorized domains → Add domain** → `naratip-prasert.github.io`
6. ⚙️ **Project settings → General → Your apps → ไอคอน `</>` (Web)** → ตั้งชื่อแอป → Register → คัดลอก `firebaseConfig`
   แล้ววางใน `js/firebase-config.js` แทน `window.TAT_FIREBASE = null;`

ใช้แผนฟรี (Spark) ได้เลย ไม่ต้องผูกบัตร · ข้อมูลเก็บที่ `users/{uid}`
